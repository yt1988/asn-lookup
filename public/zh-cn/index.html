常见问题

ASN 是什么？

ASN（自治系统号）就是一张网络在互联网上的编号。运营商、云厂商、大学、大公司，只要自己管理路由，就会有一个或几个 AS 号。比如 AS4134 是中国电信的 163 骨干网，AS13335 是 Cloudflare。

每个 AS 会向全网「宣告」自己负责哪些 IP 段（技术上叫前缀），别的网络据此把流量送过来，这套机制叫 BGP。AS 号由五大区域注册机构分配：APNIC（亚太）、RIPE NCC（欧洲和中东）、ARIN（北美）、LACNIC（拉美）和 AFRINIC（非洲）。

怎么查一个 IP 是谁家的？

在输入框里填 IP。页面会告诉你：它属于哪个 AS，也就是哪家网络；它在哪个 IP 段里；以及这段地址的登记信息：网络名称、登记组织、举报邮箱和反向解析。

负责路由的网络和登记的组织常常不是同一家。比如一家公司把服务器放在云上，IP 由云厂商宣告，登记的却可能是这家公司。想知道一个 IP 是机房 IP 还是家宽、有没有被滥用过，点结果下面的「这个 IP 干不干净」。

显示的国家/地区，就是 IP 所在的地方吗？

不一定。这里显示的是这家网络登记的国家/地区，不是这个 IP 实际在哪。

云厂商和 CDN 的机房遍布全球：一家登记在美国的网络，它的 IP 完全可能在香港或新加坡的机房里。

数据从哪来？多久更新？

IP 段来自 RIPE NCC 的路由信息服务（RIS）：它从全球几百个网络收集路由表，至少 10 个网络都看到的 IP 段才收录。IP 对应哪个 AS，用的是 iptoasn.com 的公有领域数据。名称、国家/地区和分配日期来自五大注册机构公开的文件。这些每天更新。

登记组织、举报邮箱、反向解析和相连的网络，是你打开页面时实时查询的（RDAP、DNS、RIPEstat）。

上游、下游是什么意思？

上游是这个 AS 买带宽、借以连到互联网其他地方的网络；下游是通过它上网的网络，比如它的客户。

这些关系是根据 RIPE 采集器看到的路径推断的。只在部分路径上出现的网络，多数是互相交换流量的对等网络，单独列在「对等及其他」。每一栏按经过它的路径数排序，最主要的连接排在最前面。

CN2、9929、CMI 是什么？

它们是三大运营商的精品国际网络，买 VPS 时经常看到：AS4809 是中国电信 CN2（普通骨干网是 AS4134，俗称 163），AS9929 是中国联通精品网（普通的是 AS4837，俗称 169），AS58453 是中国移动国际 CMI（国内网是 AS9808）。

一台服务器的流量走哪条线，要看回程到你这边的路由。用 traceroute 可以看到沿途经过的 AS 号。

能复制 IP 段列表吗？

可以。「复制全部」会把这个 AS 的全部 IPv4 或 IPv6 段复制下来，一行一个，可以直接贴进防火墙或代理分流规则。程序要用的话，/api/as/<AS 号> 会返回 JSON 格式的完整数据。
