常見問題

ASN 是什麼？

ASN（自治系統號碼）是網際網路上一個獨立運作路由的網路的編號，例如一家電信業者、一家雲端業者、一所大學或一家大公司。每個 AS 透過 BGP 向鄰居宣告自己負責的 IP 網段，其他網路因此知道該把流量送到哪裡。

AS 號碼由五大區域網際網路註冊機構（APNIC、RIPE NCC、ARIN、LACNIC、AFRINIC）分配。例如 AS3462 是中華電信 HiNet，AS13335 是 Cloudflare。

怎麼查一個 IP 屬於哪家？

在輸入框填入 IP 位址。頁面會顯示由哪個 AS 宣告、所在前綴，註冊機構登記的資訊（網路名稱、組織、國家/地區、濫用檢舉信箱）和反向解析。

負責路由的 AS 和登記的組織常常不是同一家：雲端業者、機房可以替客戶宣告客戶自己的網段。

資料從哪來？多久更新？

前綴來自 RIPE NCC 的路由資訊服務（RIS），它從數百個網路收集路由表，至少 10 個網路看得到的前綴才算數。IP 對應的 AS 使用 iptoasn.com（公有領域）。名稱、國家/地區和分配日期來自五大註冊機構公開的檔案。這些資料每天更新。

註冊資訊、反向解析和鄰居是在開啟頁面時即時查詢的（RDAP、DNS、RIPEstat）。

上游、下游是什麼意思？

上游是這個 AS 購買轉接的網路，或位於它和大部分網際網路之間的網路；下游是透過它連上網際網路的網路。這是根據 RIPE 收集器看到的路徑推斷的，只在部分路徑上出現的對等網路另外列出。

列表依經過每個鄰居的路徑數排序，最重要的連線排在前面。

CN2、9929、CMI 是什麼？

它們是中國大陸三大電信業者的精品國際網路，買 VPS 時常看到：AS4809 是中國電信 CN2（一般骨幹網是 AS4134，俗稱 163），AS9929 是中國聯通精品網（一般的是 AS4837，俗稱 169），AS58453 是中國移動國際 CMI（境內網路是 AS9808）。

伺服器的流量走哪一條，取決於回到你這邊的路由；用 traceroute 可以看到沿途經過的 AS 號碼。

可以複製網段清單嗎？

可以。「全部複製」會把這個 AS 的全部 IPv4 或 IPv6 前綴複製出來，一行一個，可以直接用在防火牆或代理分流規則中。任何 AS 都可以用 /api/as/<AS 號碼> 取得 JSON 格式的完整資料。
