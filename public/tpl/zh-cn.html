常见问题

ASN 是什么？

ASN（自治系统号）是互联网上一个独立运行路由的网络的编号，比如一家运营商、一家云厂商、一所大学或一家大公司。每个 AS 通过 BGP 向邻居宣告自己负责的 IP 段，互联网上的其他网络就知道该把流量送到哪里。

AS 号由五大区域互联网注册机构（APNIC、RIPE NCC、ARIN、LACNIC、AFRINIC）分配。比如 AS4134 是中国电信 163 骨干网，AS13335 是 Cloudflare。

怎么查一个 IP 属于哪家？

在输入框里填 IP 地址。页面会显示由哪个 AS 宣告、所在前缀，注册机构登记的信息（网络名称、组织、国家/地区、滥用投诉邮箱）和反向解析。

负责路由的 AS 和登记的组织经常不是同一家：云厂商、IDC 可以替客户宣告客户自己的 IP 段。

数据从哪来？多久更新？

前缀来自 RIPE NCC 的路由信息服务（RIS），它从几百个网络收集路由表，至少 10 个网络看得到的前缀才算数。IP 对应的 AS 用的是 iptoasn.com（公有领域）。名称、国家/地区和分配日期来自五大注册机构公开的文件。这些数据每天更新。

注册信息、反向解析和邻居是打开页面时实时查询的（RDAP、DNS、RIPEstat）。

上游、下游是什么意思？

上游是这个 AS 购买转接的网络，或者位于它和大部分互联网之间的网络；下游是通过它接入互联网的网络。这是根据 RIPE 采集器看到的路径推断的，只在部分路径上出现的对等网络单独列出。

列表按经过每个邻居的路径数排序，最重要的连接排在前面。

CN2、9929、CMI 是什么？

它们是三大运营商的精品国际网络，买 VPS 时常看到：AS4809 是中国电信 CN2（普通骨干网是 AS4134，俗称 163），AS9929 是中国联通精品网（普通的是 AS4837，俗称 169），AS58453 是中国移动国际 CMI（国内网是 AS9808）。

服务器的流量走哪条，取决于回到你这边的路由；用 traceroute 能看到沿途经过的 AS 号。

能复制 IP 段列表吗？

可以。「复制全部」会把这个 AS 的全部 IPv4 或 IPv6 前缀复制出来，一行一个，可以直接用在防火墙或代理分流规则里。任何 AS 都可以用 /api/as/<AS 号> 拿到 JSON 格式的完整数据。
