よくある質問

ASN とは？

ASN（AS 番号）は、インターネット上のネットワークに付けられた番号です。通信事業者、クラウド、大学、大企業など、自分で経路を管理しているネットワークが 1 つ以上持っています。例えば AS2516 は KDDI、AS13335 は Cloudflare です。

各 AS は、自分が受け持つ IP アドレス帯（専門用語ではプレフィックス）をインターネット全体に「広告」し、他のネットワークはそれを見て通信の送り先を決めます。この仕組みが BGP です。AS 番号は 5 つの地域レジストリが割り当てています：APNIC（アジア太平洋）、RIPE NCC（欧州・中東）、ARIN（北米）、LACNIC（中南米）、AFRINIC（アフリカ）。

IP アドレスの持ち主を調べるには？

入力欄に IP を入れてください。どの AS（つまりどのネットワーク）のものか、どのアドレス帯に入っているか、そしてそのアドレス帯の登録情報（ネットワーク名、登録組織、不正利用の窓口、逆引き）が表示されます。

経路を受け持つネットワークと登録上の組織は、別であることがよくあります。例えばクラウドにサーバーを置いている会社の場合、アドレスはクラウド事業者が広告していても、登録先はその会社ということがあります。データセンターの IP か家庭用回線の IP か、悪用の記録がないかを知りたいときは、結果の下の「この IP はクリーン？」を開いてください。

表示される国は、IP が実際にある場所ですか？

そうとは限りません。表示しているのはネットワークが登録されている国で、その IP が実際にある場所ではありません。

クラウドや CDN は世界中にデータセンターを持っています。米国で登録されたネットワークの IP が、香港やシンガポールにあることも普通です。

データの出どころと更新頻度は？

アドレス帯は RIPE NCC の Routing Information Service（RIS）から取得しています。世界の数百のネットワークから経路表を集めており、10 以上のネットワークから見えるものだけを載せています。IP と AS の対応は iptoasn.com（パブリックドメイン）、名前・国・割り当て日は 5 つの地域レジストリの公開ファイルです。いずれも毎日更新しています。

登録組織、不正利用の窓口、逆引き、つながっているネットワークは、ページを開いたときにその場で問い合わせています（RDAP、DNS、RIPEstat）。

上流・下流とは？

上流は、この AS が料金を払ってインターネットの他の部分とつながっている相手です。下流は、この AS を経由してインターネットにつながっている相手で、顧客などがこれにあたります。

この関係は RIPE のコレクターが見た経路から推定しています。一部の経路にしか現れないネットワーク（多くは直接通信をやり取りするピア）は「ピアなど」に分けています。各列は通る経路が多い順なので、主要な接続ほど上に来ます。

CN2、9929、CMI とは？

中国の 3 大通信事業者の高品質な国際網で、VPS の回線としてよく宣伝されています。AS4809 は China Telecom の CN2（通常のバックボーンは AS4134、通称 163）、AS9929 は China Unicom の高品質網（通常は AS4837、通称 169）、AS58453 は China Mobile International（国内網は AS9808）です。

サーバーの通信がどれを通るかは、あなたへの戻りの経路で決まります。traceroute を使うと、途中で通る AS 番号を確認できます。

アドレス帯の一覧をコピーできますか？

はい。「すべてコピー」で、その AS の IPv4 または IPv6 のアドレス帯を 1 行に 1 件ずつコピーできます。ファイアウォールやプロキシのルールにそのまま貼り付けられます。プログラムから使う場合は、/api/as/<AS 番号> でどの AS でも完全なデータを JSON で取得できます。
