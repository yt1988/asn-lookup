よくある質問

ASN とは？

ASN（自律システム番号）は、インターネット上で独自に経路制御を行うネットワークの番号です。通信事業者、クラウド、大学、大企業などが持っています。各 AS は担当する IP プレフィックスを BGP で隣接ネットワークに広告し、それによって他のネットワークは通信をどこへ送ればよいかを知ります。

番号は 5 つの地域インターネットレジストリ（APNIC、RIPE NCC、ARIN、LACNIC、AFRINIC）が割り当てます。例えば AS2516 は KDDI、AS13335 は Cloudflare です。

IP アドレスの持ち主を調べるには？

入力欄にアドレスを入れてください。そのアドレスを広告している AS とプレフィックス、登録機関の記録（ネットワーク名、組織、国、不正利用の連絡先）、逆引きが表示されます。

経路を広告している AS と登録上の組織は、しばしば別です。クラウドやホスティング会社が顧客自身のアドレスブロックを広告することがあります。

データの出どころと更新頻度は？

プレフィックスは RIPE NCC の Routing Information Service（RIS）から取得しています。数百のネットワークから経路表を集めており、10 以上のネットワークから見えるプレフィックスだけを載せています。アドレスから AS への対応は iptoasn.com（パブリックドメイン）、名前・国・割り当て日は 5 つのレジストリの公開ファイルです。どれも毎日更新します。

登録情報、逆引き、隣接 AS はページを開いたときにリアルタイムで問い合わせます（RDAP、DNS、RIPEstat）。

上流・下流とは？

上流は、この AS がトランジットを買っているネットワーク、またはこの AS とインターネットの大部分の間にあるネットワークです。下流は、この AS を通ってインターネットにつながるネットワークです。RIPE のコレクターが見た経路から推定しているため、一部の経路にしか現れないピアは別にまとめています。

経由する経路の数が多い順なので、重要な接続ほど上に来ます。

CN2、9929、CMI とは？

中国の 3 大通信事業者の高品質な国際網で、VPS の回線としてよく宣伝されます。AS4809 は China Telecom の CN2（通常のバックボーンは AS4134、通称 163）、AS9929 は China Unicom の高品質網（通常は AS4837、通称 169）、AS58453 は China Mobile International（国内網は AS9808）です。

サーバーの通信がどれを通るかは、あなたへの戻りの経路で決まります。traceroute で途中の AS 番号を確認できます。

プレフィックスの一覧をコピーできますか？

はい。「すべてコピー」で、その AS の IPv4 または IPv6 プレフィックスを 1 行に 1 つずつコピーできます。ファイアウォールやプロキシのルールにそのまま使えます。/api/as/<AS 番号> では、どの AS でも完全なデータを JSON で取得できます。
